AI Resume Scorer

----------------------

An AI-powered resume analysis tool that extracts information from resumes, compares them against predefined criteria, and generates structured scores and 
feedback using Groq LLMs.

-----------------------

Features

- Upload PDF resumes
- Extract resume information
- Structured data extraction using Pydantic
- AI-powered resume evaluation
- Resume scoring
- JSON output

-------------------------

Tech Stack

- Python
- Groq API
- Llama 3.3 70B
- Pydantic
- dotenv
- JSON
